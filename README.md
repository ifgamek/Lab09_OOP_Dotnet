# Собственный проект

1. Тема проекта : GuildHeros

2. Главные классы : Heroes , Inventory

3. Почему эти объкты нужны программе : благодаря ним доступна возможность создавать новых героев со своим инветорем

4. Какие данные хранят объекты :

- Name- героя и имя предмета
- Health
- level
- Experienceb
- Massa
- Drop
- Use

5. Какие значения задаются через конструктор :

- Name - и имя героя и название предмета
- Health
- Massa

6. Какие значения можно задавать автоматически :

- level
- Experience
- Use
- Drop
